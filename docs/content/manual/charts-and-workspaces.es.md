## Crear o editar una carta

Abra **Nuevo** desde la barra lateral principal. Introduzca la identidad de la carta, la fecha y hora, la ubicación, el sistema de casas y otras opciones disponibles. Al crear la carta, esta se añade al espacio de trabajo actual y se vuelve al panel de carta natal.

Para revisar una carta existente, selecciónela en el panel y use su acción de edición. Guardar el formulario actualiza esa carta en lugar de crear otra.

## Abrir un espacio de trabajo

Abra **Abrir** y elija una carpeta de espacio de trabajo. Kefer carga las cartas y los valores predeterminados de nivel de espacio de trabajo almacenados allí. Al seleccionar una carta, se vuelve al panel de carta natal.

## Guardar un espacio de trabajo

Use **Guardar** para escribir la colección actual de cartas y valores predeterminados. Cuando aún no se ha seleccionado ninguna carpeta de espacio de trabajo, la aplicación de escritorio le pide que elija una.

## Exportar

Use **Exportar** para obtener una salida portátil destinada a salir del espacio de trabajo actual. Guardar conserva el espacio de trabajo editable; exportar produce una representación independiente para otro fin.
