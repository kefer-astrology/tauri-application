## Create or edit a chart

Open **New** from the primary sidebar. Enter the chart identity, date and time, location, house system, and other available options. Creating the chart adds it to the current workspace and returns you to the horoscope dashboard.

**Time system** chooses the calendar or date format used to enter and read the
chart's date: **Gregorian**, **Julian Day**, **Julian Calendar**, **Unix
Timestamp**, **Ordinal Date**, **ISO Week Date**, or **Compact Date**. It is
stored with the chart and shown back on its record; it does not change the
timezone.

Location and timezone can each be set to **Auto** or **Manual**. Auto records
that the value came from a lookup, such as searching for a place name;
Manual records that you entered the coordinates or timezone yourself. Both
modes are stored independently for location and timezone, so a chart can mix
an auto-resolved place with a manually entered timezone, or the reverse.

To revise an existing chart, select it from the dashboard and use its edit action. Saving the form updates that chart instead of creating another one.

## Open a workspace

Open **Open** and choose a workspace folder. Kefer loads the charts and workspace-level defaults stored there. Selecting a chart returns you to the horoscope dashboard.

## Save a workspace

Use **Save** to write the current collection of charts and defaults. When no workspace folder has been selected yet, the desktop application asks you to choose one.

## Export

Use **Export** for portable output intended to leave the current workspace. Saving preserves the editable workspace; exporting produces a separate representation for another purpose.
