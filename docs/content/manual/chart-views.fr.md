## Thème

Le tableau de bord Thème est la vue principale du thème. Il combine le thème sélectionné, sa roue, les onglets contextuels et les contrôles utilisés pour l’examiner ou le modifier.

## Aspects

Les aspects comparent les objets observables sélectionnés dans une matrice. Sélectionnez une cellule d’aspect disponible pour en examiner les détails. Les cellules vides doivent être lues comme l’absence d’un aspect calculé, et non comme des données décoratives manquantes.

## Informations

La vue Informations présente les détails calculés du thème sous une forme orientée rapport. Utilisez-la lorsque les positions exactes et les valeurs associées comptent plus que la roue.

## Révolution et synastrie

La révolution fournit un flux spécialisé de retour temporel. La synastrie compare deux personnes ou deux thèmes. Certaines parties de ces vues restent en cours de développement actif ; l’interface doit rendre explicites les calculs indisponibles plutôt que de présenter des résultats inventés.
