Jde o stejné sestavení, jaké vkládají Řízené prohlídky, ale bez parametru dotazu tour, takže se nepřipojí žádný překryv a žádný cíl se automaticky neaktivuje. Otevřená je každá navigační cesta k přímému otestování — včetně vytvoření nového horoskopu, úpravy štítků nebo přepínání pracovních prostorů.
