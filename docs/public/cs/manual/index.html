Manuál

Praktická nápověda pro práci s horoskopy, časem, pracovními prostory a nastavením aplikace.

Manuál popisuje aplikaci Kefer Astrology z pohledu uživatele. Není třeba znát, jak je aplikace implementována.

Začínáme

  • Začínáme — pochopte pracovní prostor a hlavní navigaci.
  • Horoskopy a pracovní prostory — vytvářejte, otevírejte, upravujte, ukládejte a exportujte svou práci.

Prozkoumání horoskopu

  • Zobrazení horoskopu — přepínejte mezi zobrazeními Horoskop, Aspektárium, Informace, Revoluce a Synastrie.
  • Tranzity a čas — prozkoumejte konkrétní okamžik, procházejte časem a pracujte se zobrazeními tranzitů.

Přizpůsobení aplikace

  • Nastavení a vzhled — zvolte jazyk, vizuální motivy, glyfy, objekty, aspekty a výchozí hodnoty pro výpočty.

Pokud se raději učíte prozkoumáváním rozhraní, otevřete Průvodce pro volnou ukázku nebo scénářem řízenou prohlídku.
