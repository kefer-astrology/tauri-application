Kefer Astrology

Aprenda a usar la aplicación, explórela de forma interactiva o trabaje con sus contratos técnicos.

Kefer Astrology es un espacio de trabajo de escritorio para crear, examinar y comparar cartas astrológicas.

Elija la ruta que corresponda a lo que quiere hacer:

  • Manual explica la aplicación a través de tareas prácticas y flujos de trabajo astrológicos habituales.
  • Manual para desarrolladores documenta la arquitectura, los contratos, las reglas de implementación y los flujos de desarrollo.
  • Guías permiten abrir libremente cualquiera de las compilaciones seguras para navegador, o seguir recorridos guiados de Inicio rápido, Funciones de Radix, Cálculo de tránsitos y Ajustes.

El Manual es el punto de partida adecuado cuando quiere usar Kefer Astrology. El Manual para desarrolladores es la fuente de verdad cuando quiere entender o modificar su funcionamiento.
