Manual

Ayuda orientada a tareas para trabajar con cartas, tiempo, espacios de trabajo y ajustes de la aplicación.

El Manual describe Kefer Astrology desde el punto de vista del usuario. No necesita saber cómo está implementada la aplicación.

Empezar

  • Primeros pasos — comprenda el espacio de trabajo y la navegación principal.
  • Cartas y espacios de trabajo — cree, abra, edite, guarde y exporte su trabajo.

Examinar una carta

  • Vistas de carta — muévase entre las vistas de carta natal, aspectos, información, revolución y sinastría.
  • Objetos, aspectos y patrones de carta — consulte el catálogo integrado y de qué depende su disponibilidad.
  • Tránsitos y tiempo — inspeccione un momento, navegue por el tiempo y trabaje con las vistas de tránsito.

Personalizar la aplicación

  • Ajustes y apariencia — elija idioma, temas visuales, glifos, objetos, aspectos y valores predeterminados de cálculo.

Si prefiere aprender explorando la interfaz, abra las Guías para una vista previa libre o un recorrido guiado.
