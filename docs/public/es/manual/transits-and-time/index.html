Tránsitos y tiempo

Inspeccione posiciones cambiantes y desplace una carta a través del tiempo.

Abra Tránsitos para comparar una carta radix seleccionada con las posiciones de otro momento. Use su navegación secundaria para elegir la operación de tránsito disponible.

Dinámica utiliza la misma parte de la aplicación orientada al tiempo para flujos de trabajo de movimiento y rango más amplios. Los controles distinguen un instante único de una serie temporal generada.

Cuando la navegación temporal está disponible, elija una unidad y una cantidad antes de avanzar o retroceder. Las unidades sensibles al calendario, como los meses y los años, se aplican como cambios de calendario en lugar de números fijos de segundos.

La carta seleccionada sigue siendo el punto de referencia a menos que la interfaz muestre explícitamente una vista previa temporal o una superposición de tránsito.
