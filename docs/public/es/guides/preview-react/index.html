Compilación React

La compilación React completa y segura para navegador, sin superposición de recorrido guiado.

Compilación React Compilación Svelte

Abrir a pantalla completa ↗

Esta es la misma compilación que incrustan los Recorridos Guiados, sin el parámetro de consulta tour, por lo que no se adjunta ninguna superposición y no se activa automáticamente ningún objetivo. Todas las rutas de navegación —incluida la creación de una carta nueva, la edición de etiquetas o el cambio de espacio de trabajo— están abiertas para probarse directamente.
