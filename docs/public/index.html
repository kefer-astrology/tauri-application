Kefer Astrology

Learn the application, explore it interactively, or work with its technical contracts.

Kefer Astrology is a desktop workspace for creating, examining, and comparing astrological charts.

Choose the path that matches what you want to do:

  • Manual explains the application through practical tasks and familiar astrological workflows.
  • Developer Manual documents architecture, contracts, implementation rules, and development workflows.
  • Guides open either browser-safe frontend build freely, or follow scripted walkthroughs for Quickstart, radix features, transit computation, and settings.

The Manual is the right starting point when you want to use Kefer Astrology. The Developer Manual is the source of truth when you want to understand or change how it works.
