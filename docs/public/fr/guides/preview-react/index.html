Version React

La version React complète compatible navigateur, sans superposition de visite guidée.

Version React Version Svelte

Ouvrir en pleine page ↗

Il s’agit de la même version que celle intégrée par les Visites Guidées, sans le paramètre de requête tour, de sorte qu’aucune superposition ne s’attache et qu’aucune cible n’est activée automatiquement. Chaque parcours de navigation — y compris la création d’un nouveau thème, la modification des étiquettes ou le changement d’espace de travail — est ouvert pour être testé directement.
