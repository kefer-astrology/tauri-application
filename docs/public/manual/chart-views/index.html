Chart views

Choose the view that answers the question you are asking of a chart.

Horoscope

The horoscope dashboard is the main chart view. It combines the selected chart, its wheel, context tabs, and the controls used to inspect or edit it.

Aspectarium

The aspectarium compares the selected observable objects in a matrix. Select an available aspect cell to inspect its details. Empty cells should be read as the absence of a computed aspect, not as missing decorative data.

Information

The information view presents calculated chart details in a report-oriented form. Use it when exact positions and related values matter more than the wheel.

Revolution and synastry

Revolution provides a specialized time-return workflow. Synastry compares two people or charts. Some parts of these views remain under active development; the interface should make unavailable calculations explicit rather than presenting invented results.
